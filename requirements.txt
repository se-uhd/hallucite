# Python dependencies for the hallucinated-reference audit pipeline.
#
# `hallucinator` provides both reference extraction (PdfExtractor) and
# multi-database verification (Validator: offline DBLP + CrossRef/arXiv/
# Semantic Scholar/...). It ships prebuilt wheels targeting
# CPython 3.12 — mise.toml pins python = "3.12" so pip resolves a wheel
# instead of building from source (which would need Rust + maturin).
#
# The driver scripts (audit_references.py, triage.py, pdf_references.py) otherwise use
# only the Python standard library, except that pdf_references.py shells out to
# `pdftotext` (poppler) for PDF text extraction.
#
# Pin the exact version after the first install:  uv pip freeze | grep -i hallucinator
