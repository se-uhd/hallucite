# Python dependencies for the hallucinated-reference audit pipeline.
#
# There are none. Reference extraction (`pdf_references.py`), parsing
# (`reference_parser.py`) and verification (`verifier.py`, `dblp_check.py`) are hallucite's own and
# use only the standard library, except that `pdf_references.py` shells out to `pdftotext`
# (poppler) for PDF text extraction.
#
# `hallucinator` is not imported by anything, `characterize.py record` included: a new recording is
# made from hallucite's own modules.
#
# One task has a dependency, and only that task: `mise run fetch-dblp-dump` drives a real browser,
# because dblp.org fronts the dump with a proof-of-work challenge no plain HTTP client answers.
#
#     pip install playwright && playwright install chromium
